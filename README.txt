InteractLLM:

InteractLLM is a free LLM tool which runs on PCs that don't cost a fortune.

features: 
Low hallucination rate
Efficient Image Scanning
Gives unique answers
Can solve Mathematics (Up till Algebra)
Requires NO water to run

Setup:
Install Ollama (On Windows)
In CMD, put "Ollama"
Then put "Ollama pull Llama3.2:1b"
After, run "pip install moondream"
Then, run "pip install sqlite3" (This might already be on your computer)
Just make sure you have Python installed
then go to InteractLLM_For_x86\dist then double-click InteractLLM_x86.exe to start

Minimum requirements
2-Core CPU with AVX2 support (AMD64, Like most CPU after 2013)
8GB of Dedicated RAM 
5GB of free space
Integrated Graphics Processing Unit

Recommended Requirements:
4-Core or more CPU with AVX2 support (AMD64)
16GB of Dedicated RAM
NVIDIA or AMD Dedicated Graphics Processing Unit
4-6GB or more of VRAM
25GB of free space

Highest Officially Supported Requirements for AMD64:
128-Core CPU with AVX2 support
64 Gigabytes of Dedicated RAM
NVIDIA NVLink A100s 
160GB of VRAM
1TB of Free space
